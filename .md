To fully localize your setup, we will create a dedicated `LocalProxyManager` alongside the `LocalServerManager`. This ensures that if you set `proxy_url="local"`, the CLI downloads your `gammam3u8proxy` repo, installs its specific dependencies, and runs it on port `5010`.

Here are the modular updates for `pyanimecli.py`:

### 1. Update Global Config & Settings
Update the mappings so the CLI knows what "local" means for both the API and the Proxy.

```python
# Mappings for keywords
HOST_MAP = {
    "default": "https://yumaapi.vercel.app",
    "local": "http://localhost:8192"
}

PROXY_MAP = {
    "default": "https://gammam3u8proxy-fxsb.vercel.app/cors?url=",
    "local": "http://localhost:5010/cors?url="
}

DEFAULT_SETTINGS = {
    "host": HOST_MAP["local"],
    "proxy_url": PROXY_MAP["local"], # Default to local proxy
    "source": "sub",
    "player": "vlc",
    "auto_update": True,
    "download_path": str(Path.home() / "Downloads" / "Anime")
}

# In Settings.update(), handle the proxy_url keyword
def update(self, key, value):
    if key == "host":
        self.data[key] = HOST_MAP.get(value.lower(), value)
    elif key == "proxy_url":
        self.data[key] = PROXY_MAP.get(value.lower(), value)
    elif value.lower() == "default" and key in DEFAULT_SETTINGS:
        self.data[key] = DEFAULT_SETTINGS[key]
    else:
        self.data[key] = value
    self.save()
```

### 2. The Local Proxy Manager
This class mirrors the Server Manager but targets the `gammam3u8proxy` repository.

```python
class LocalProxyManager:
    REPO_ZIP = "https://github.com/princevegetadev/gammam3u8proxy/archive/refs/heads/main.zip"
    PROXY_DIR = CONFIG_DIR / "proxy_files"
    
    def is_running(self):
        try:
            # Check port 5010 (the default in your main.py)
            requests.get("http://localhost:5010/cors?url=http://google.com", timeout=1)
            return True
        except:
            return False

    def install_or_update(self):
        console.print("[yellow]Installing/Updating Local CORS Proxy...[/yellow]")
        r = requests.get(self.REPO_ZIP)
        with zipfile.ZipFile(io.BytesIO(r.content)) as z:
            z.extractall(self.PROXY_DIR)
        
        extracted_folder = next(self.PROXY_DIR.glob("gammam3u8proxy-*"))
        
        # Install specific requirements (fastapi, uvicorn, etc.)
        subprocess.run([sys.executable, "-m", "pip", "install", "-r", str(extracted_folder / "requirements.txt")], 
                       stdout=subprocess.DEVNULL)
        
        (self.PROXY_DIR / ".latest").write_text(str(time.time()))

    def start_headless(self):
        if self.is_running():
            return

        # Check if files exist, if not, download
        if not list(self.PROXY_DIR.glob("gammam3u8proxy-*")):
            self.install_or_update()

        extracted_folder = next(self.PROXY_DIR.glob("gammam3u8proxy-*"))
        console.print("[cyan]Launching Local Proxy Server (Port 5010)...[/cyan]")
        
        subprocess.Popen(
            [sys.executable, "main.py"],
            cwd=str(extracted_folder),
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            creationflags=subprocess.CREATE_NO_WINDOW if platform.system() == "Windows" else 0
        )
        time.sleep(2)
```

### 4. CLI Usage Examples
Now that you've added these, you can manage everything via the terminal:

*   **Switch everything to local (offline mode):**
    ```bash
    pyanimecli --settings host=local proxy_url=local
    ```
*   **Use local API but official Vercel Proxy:**
    ```bash
    pyanimecli --settings host=local proxy_url=default
    ```
*   **Custom Host (Your own VPS):**
    ```bash
    pyanimecli --settings host="http://1.2.3.4:8080"
    ```
*   **Reset everything:**
    ```bash
    pyanimecli --settings host=default proxy_url=default source=default
    ```

### Why this works:
1.  **Independent Environments**: `LocalServerManager` and `LocalProxyManager` manage their own folders inside `~/.pyanimecli/`. They won't conflict.
2.  **Headless Execution**: `subprocess.Popen` ensures the servers stay alive in the background while the CLI is running, and `CREATE_NO_WINDOW` keeps it clean on Windows.
3.  **Port Separation**: API on `8192` and Proxy on `5010` allows them to run simultaneously without address conflicts.
4.  **Auto-Install**: If you delete the `~/.pyanimecli` folder, simply running any command like `pyanimecli -s "naruto"` will trigger the automatic download and setup of both the API and the Proxy.
